ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ
Приложение «Сканер кодов» (ru.codescanner.app)
Редакция от 20 ноября 2026 г.

1. ОБЩИЕ ПОЛОЖЕНИЯ

1.1. Приложение «Сканер кодов» предназначено для считывания штрихкодов
(DataMatrix, QR, Code-128, EAN-13 и других), ведения журнала на устройстве
и выгрузки журнала в файл.

1.2. Приложение не требует регистрации и не создаёт учётных записей.
Разработчик не получает доступ к отсканированным кодам и настройкам
приложения. Бесплатная версия приложения не имеет доступа в интернет.

1.3. Оператор персональных данных: Коновалов Александр Валентинович,
контакт: Likan_military@bk.ru.

2. КАКИЕ ДАННЫЕ ОБРАБАТЫВАЮТСЯ

2.1. Данные, которые хранятся только на устройстве:
- отсканированные коды, дата и время сканирования, тип кода, GTIN,
серийный номер и криптографические хвосты (91/92/93) — в локальной
базе данных приложения;
- настройки приложения: формат выгрузки, папка сохранения, тема, язык,
окно защиты от дублей, звук, вибрация, подсветка экрана.

Эти данные не передаются разработчику и не покидают устройство.

2.2. Камера.
Кадры камеры обрабатываются исключительно на устройстве и не сохраняются.
Изображения не загружаются на серверы разработчика или Google.

2.3. Диагностические данные ML Kit (Google).
Распознавание штрихкодов выполняется библиотекой Google ML Kit.
Изображения обрабатываются на устройстве. Библиотека ML Kit содержит
компоненты, которые в версиях приложения с доступом в интернет могут
передавать в Google обезличенные диагностические и статистические данные:
- сведения об устройстве (производитель, модель, версия и сборка ОС)
и доступных аппаратных ускорителях;
- имя и версию приложения;
- идентификаторы установки, не предназначенные для однозначного
определения пользователя или устройства;
- метрики производительности, типы событий, коды ошибок, конфигурацию
и версию используемого API.

В бесплатной версии приложению не разрешён доступ в интернет, поэтому
такая передача невозможна. В версиях с доступом в сеть данные
используются Google для диагностики, поддержки и улучшения SDK
и передаются по HTTPS. Подробнее:
https://developers.google.com/ml-kit/android-data-disclosure
и https://policies.google.com/privacy

2.4. Приложение не содержит рекламы, не использует собственных систем
аналитики и не собирает контакты, геолокацию, списки звонков, SMS,
файлы пользователя и иные данные, не перечисленные выше.

3. ПЕРЕДАЧА ДАННЫХ ТРЕТЬИМ ЛИЦАМ

3.1. Разработчик не продаёт и не передаёт данные пользователей
третьим лицам.

3.2. В бесплатной версии передача данных третьим лицам не выполняется:
доступ в интернет приложению не разрешён. Диагностические данные ML Kit
могут передаваться Google только в версиях, которым разрешён доступ
в сеть (раздел 2.3).

4. ЦЕЛИ ОБРАБОТКИ

4.1. Работа основных функций приложения: сканирование, журнал,
защита от повторной записи кодов и выгрузка журнала в файл.

4.2. Диагностика и улучшение работы библиотеки распознавания (Google) —
в версиях приложения с доступом в интернет.

5. СРОКИ ХРАНЕНИЯ И УДАЛЕНИЕ

5.1. Журнал кодов и настройки хранятся на устройстве до их удаления
пользователем.

5.2. Удалить журнал можно в приложении: «История» → удалить запись или
«Очистить всё». Полное удаление данных приложения выполняется средствами
Android: «Настройки» → «Приложения» → «Сканер кодов» → «Хранилище» →
«Очистить данные», либо удалением приложения.

5.3. Диагностические данные ML Kit, если они передавались, хранятся
в Google согласно политике конфиденциальности Google; разработчик
не имеет к ним доступа и не может удалить их по запросу пользователя.

8. БЕЗОПАСНОСТЬ

PRIVACY POLICY
"Code Scanner" app (ru.codescanner.app)
Version dated 20 November 2026

1. GENERAL

1.1. "Code Scanner" reads barcodes (DataMatrix, QR, Code-128, EAN-13 and
others), keeps a local log on the device and exports the log to a file.

1.2. The app requires no sign-up and creates no accounts. The developer has
no access to scanned codes or app settings. The free version of the app has
no internet access.

1.3. Data controller: Alexander Valentinovich Konovalov,
contact: Likan_military@bk.ru.

2. DATA PROCESSED

2.1. Data stored on the device only:
- scanned codes, scan date and time, code type, GTIN, serial number and
cryptographic tails (91/92/93) in the app's local database;
- app settings: export format, save folder, theme, language, duplicate
window, sound, vibration, screen flash.

This data is not transferred to the developer and does not leave the device.

2.2. Camera.
Camera frames are processed on the device only and are not stored. Images
are not uploaded to the developer's or Google's servers.

2.3. ML Kit diagnostics (Google).
Barcode recognition is performed by Google ML Kit. Images are processed
on the device. ML Kit contains components that, in app versions with
internet access, may send anonymous diagnostics and usage data to Google:
- device information (manufacturer, model, OS version and build) and
available ML hardware accelerators;
- package name and app versions;
- per-installation identifiers not intended to identify a user or device;
- performance metrics, event types, error codes, API configuration and
version.

The free version of the app has no internet permission, so such transfer
is not possible. In versions with network access Google uses this data for
diagnostics, maintenance and improvement of the SDK; transfer is encrypted
with HTTPS. For details see
https://developers.google.com/ml-kit/android-data-disclosure
and https://policies.google.com/privacy

2.4. The app contains no ads, uses no own analytics and does not collect
contacts, location, call logs, SMS, user files or any other data not listed
above.

3. DISCLOSURE TO THIRD PARTIES

3.1. The developer does not sell or share user data with third parties.

3.2. The free version does not disclose data to third parties: the app has
no internet permission. ML Kit diagnostics may be sent to Google only in
versions with network access (section 2.3).

4. PURPOSES

4.1. Core features: scanning, log, duplicate protection and export to a
file.

4.2. Diagnostics and improvement of the recognition library (Google) in
app versions with internet access.

5. RETENTION AND DELETION

5.1. The code log and settings are stored on the device until the user
deletes them.

5.2. The log can be deleted in the app: "History" -> delete an entry or
"Clear all". Full deletion of app data is done via Android settings:
"Settings" -> "Apps" -> "Code Scanner" -> "Storage" -> "Clear data", or by
uninstalling the app.

5.3. ML Kit diagnostics, if transferred, are retained by Google under
Google's privacy policy; the developer has no access to them and cannot
delete them on the user's behalf.

6. USER RIGHTS

6.1. The user may:
- view and delete scanned codes in the app;
- change app settings;
- revoke the camera permission in Android settings;
- delete all app data via Android.

6.2. Data protection requests: Likan_military@bk.ru.

7. CHILDREN

7.1. The app is not directed to children and is not intended to collect
data about children.

8. SECURITY

8.1. App data is stored in the device's protected app storage accessible
only to the app.

8.2. The free version does not transfer data over the network and does not
store passwords or credentials of third-party services.

9. CHANGES

9.1. The current version of this policy is available in the app:
"Settings" -> "Privacy policy", and at:
https://likanwf.github.io/ru.codescanner/
9.2. When processing changes, the version date is updated.
